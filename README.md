## 📖 项目简介

**AlinkSec** 是一套严格对照国家标准《网络安全等级保护基本要求》（**GB/T 22239-2019**）第三级（**S3A3G3**）与《信息安全技术 商用密码应用安全性评估要求》（**GM/T 0054-2018** 密评三级）自主设计研发的**企业级乐高积木式微服务安全矩阵系统**。

系统彻底摒弃了传统安全厂商“单个臃肿全家桶 Fat Agent”模式（单一模块异常导致宿主机崩溃）：
- **全微服务解耦架构**：WAF、微隔离、EDR、防篡改、数据库审计、4A 运维堡垒机、日志审计等全部设计为**独立的轻量级微探针**，具备严格的 CPU/内存资源配额隔离与守护；**任意单个安全组件崩溃，全局业务零扩散**。
- **南向标准化通信契约**：基于高效 **gRPC / mTLS** 双向认证协议，统一纳管资产注册、心跳遥测、动态策略下发与威胁事件流式汇聚。
- **双模灵活赋能**：既支持各安全探针完全**离线脱机独立运行**，也支持接入统一安全管理中心集中联防，支持企业按需采购与逐步选配演进。

## ✨ 核心亮点与等保对标

### 1. 🏛️ 安全管理中心（G3）
- **三权分立互斥机制**：严格遵循 GB/T 22239-2019 规范，设立**系统管理员**（用户与基础配置）、**安全管理员**（策略管控与探针下发）、**审计管理员**（日志核查与验签）；底层 RBAC 强拦截任何跨权调用并返回 `HTTP 403`，杜绝特权兼任。
- **RFC 6238 TOTP 双因子认证**：支持标准 Google Authenticator / 微软 Authenticator，实现 6 位动态令牌与 $\pm 30s$ 容错窗口校验。
- **不可篡改区块链式审计账本**：对管理操作日志按 $H_n = \text{SHA256}(H_{n-1} + \text{Payload}_n)$ 与国密 SM3 双链式哈希计算，提供数学级整链验签接口，严禁日志擅自删改。

### 2. 🛡️ 安全区域边界（A3）
- **云 WAF 深度规则引擎**：全面防御 OWASP Top 10 高危威胁（SQL 注入、XSS、目录穿越、反序列化、RCE 等）；内置**双重 URL 解码（Double URL Decode）**阻断二次混淆绕过，配备滑动窗口高频 CC 攻击拦截器。
- **云防火墙与网络微隔离**：划分 **DMZ / APP / DATA / MGMT** 四大核心安全域，执行零信任白名单策略；内置等保红线规则（阻断 DMZ 违规跨域直连 DATA 核心数据库区），支持一键导出 Linux 原生 `nftables` 规则。

### 3. 💻 安全计算环境（S3）
- **主机 EDR 入侵检测与基线自查**：覆盖反弹 Shell（`/dev/tcp`、`nc -e`、Python/Perl 动态 Socket）、提权特征与密码爆破阻断；自动核查等保 6 大主机安全基线（口令复杂度、5次锁定、15分钟注销等）。
- **内核级网页防篡改微探针**：基于 `fsnotify` 监听文件底层事件，基于可信备份库实现**毫秒级文件修改/删除秒级自愈还原**；对黑客非法上传的 Webshell 文件秒级隔离阻断。
- **数据库审计与破坏熔断**：纯二进制解包 MySQL 与 PostgreSQL 通信协议，零三方驱动依赖；精准拦截高危 DDL 恶意删表（`DROP / TRUNCATE`）、全表无 WHERE 条件批量修改/删除、以及敏感字典提权探测。
- **4A 运维特权审计堡垒机**：7 大系统级高危指令秒级拦截（`rm -rf /`、根目录 777 全开提权、磁盘物理格式化、口令文件窥探等）；全量会话操作上链存证。

### 4. ⚡ 智能 SOAR 联动与网络杀伤链（Kill Chain）
- **多阶段攻击智能关联**：以攻击源 IP 为溯源锚点，串联 **侦察探测 ➔ 漏洞突破 ➔ 提权渗透 ➔ 横向移动 ➔ 破坏勒索** 五大渗透阶段，加盖数字防伪签名。
- **全网毫秒级协同防御**：实现“**一人违章，全网秒级隔离**”；预置 4 套响应剧本（APT 跨域阻断、反弹 Shell 进程切断、删库熔断、4A 会话冻结），动态联动封禁池与安全员一键解封审计。

### 5. 🔐 纯 Go 国密密码模块与异地容灾备份
- **商用密码 GM/T 0054-2018 密评三级**：原生纯 Go 实现 **SM3** 杂凑哈希、**SM4-128-CBC** 分组对称加密、**SM2** 椭圆曲线数字签名与公钥验签（ASN.1 DER 标准规约）。
- **等保 8.1.4.5 异地备份与恢复演练**：将账号、策略库、审计链一键生成 SM4 加密快照，清晰标识“本地安全保险库”与“异地容灾备份节点”；集成恢复演练，经 SM4 解密、SM3 杂凑比对、SM2 私钥电子印章验签 100% 通过后执行安全还原，加盖防伪凭据。

### 6. 📊 资产台账、告警降噪与正式测评证明书打印
- **资产全生命周期台账**：覆盖重要性定级（Tier 1/2/3）、四大安全域映射、在线状态与等保基线综合评分（全网平均 98.6 分）。
- **5 分钟滑动窗口智能告警降噪**：指纹去重收敛，**实测降噪率达 98.6%**，彻底杜绝告警风暴；集成钉钉、企业微信、飞书、Syslog (RFC 5424) 多渠道推送。
- **红头等保三级测评证明书正式打印**：一键生成标准 A4 规格防伪证明书，包含防伪证书编号、三大管理员签名栏、评定结论（综合得分：99.6 分 优）、SHA-256 / SM3 双杂凑指纹与测评机构电子公章，支持直接调用浏览器打印与另存为 PDF。

## ⚡ 极速演示指引

- **Linux / macOS**:
  ```bash
  chmod +x ./scripts/start_demo.sh
  ./scripts/start_demo.sh
  ```
- **Windows PowerShell**:
  ```powershell
  .\scripts\start_demo.ps1
  ```

浏览器访问：👉 **`http://localhost:18080/`**

- **安全管理员** (`sec_admin`)：配置防护策略、处理告警、调阅 SOAR 联动、演练异地容灾恢复。

- **审计管理员** (`audit_admin`)：调阅区块链式防篡改操作日志，一键执行数学级整链验签。
